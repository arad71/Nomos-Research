This directory contains database migrations that are run using [Alembic](https://alembic.sqlalchemy.org/en/latest/).

Please see the section in the base [README.md](../../../README.md) about database migrations.

Contents of this directory:

```shell
├── env.py # configuration
├── __init__.py # module initialisation file
├── README.md # this file
├── script.py.mako # template database migration that gets used when generating a migration using the alembic cli
└── versions # individual database migrations
```
